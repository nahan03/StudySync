01 What is StudySync?

StudySync is a personalised study platform built for students who want structure, focus, and motivation all in one place. Instead of juggling separate apps for notes, timers, flashcards, schedules, and music, StudySync unifies everything into one coherent environment — with three distinct study modes, each with its own visual identity and purpose.

🌱
Core Concept

Studying should feel like growth. The metaphor throughout the app is a living forest — trees grow as you complete sessions, leaves fall in the background, and your progress has a visual life to it.

🌱
Daily Mode

Steady growth through consistent daily habits. Resources, notes, AI coach, and a living forest background.

🌌
Exam Mode

Night sky cosmic theme. Hero timer ring, exam countdown, AI flashcards and practice questions.

🍂
Custom Mode

Full control over time blocks, goals, and session structure. Adapts to any study style.

Why no React or Vue?

03 Pages & Features

Home Page /

Onboarding Session Planner Active Session Widget

The landing page and launchpad. First-time visitors see an onboarding modal that captures their grade (6–12) and subjects. This profile is saved in localStorage and pre-fills the session planner going forward.

Three mode cards animate on hover to reveal feature lists. Clicking a card opens an inline session planner asking: subject, topic, hours available, deadline in days, and session goal. This creates a "plan" object passed into whichever mode is launched.

An Active Session Widget floats bottom-left on the home page — if a session was left running on another tab, it shows the live countdown and a "Back to Session" button. The profile avatar dropdown (top-right) shows grade, subjects, streak count, and links to Forest and Stats.

Daily Mode /daily/

Timer Resources PDF Viewer AI Coach Study Tree

Visual Theme: Deep forest — three layers of SVG tree silhouettes (far pine, mid oak, near oak), animated floating leaf emojis, atmospheric green radial glows, and a ground mist layer. Everything feels like studying inside a forest at dusk.

Two-column layout: Left sidebar holds the SVG ring timer, a session goal input, and a vertical 5-node timeline. Right main area holds the Resources panel.

  • Pomodoro timer — Up to 5 sessions. Each completed session advances the study tree by one growth stage. Auto-break triggers a "Watering your tree" overlay with animated water drops.
  • Session complete overlay — Shows the tree at its current stage with a species fact. The streak counter increments and saves.
  • Resources panel — Save links (URL + title + subject + chapter) or upload PDFs/DOCX files stored in IndexedDB. Filter by subject, search by keyword.
  • In-app PDF Viewer — Full-screen overlay with page navigation. Three side panel tabs: AI Summary, Chat with PDF, and Annotations (highlights + bookmarks, all stored in IndexedDB).
  • Dictionary lookup — Select any word → "Define" tooltip appears → click for definition, phonetics, and audio pronunciation from the free Dictionary API.
  • AI Study Coach — Slide-in chat sidebar. Groq AI has your notes and subject as context. Quick chips: "Quiz me", "What should I focus on". Markdown + LaTeX math rendered in output.
  • Study Tree Widget — Floating bottom-right pill. Canvas-drawn tree grows through 5 stages. Tree species changes by subject (Maths = Austrian Pine, History = Ancient Olive, Literature = Cherry Blossom, Science = Giant Sequoia). Particle burst fires on completing all 5 sessions.

Exam Mode /exam/

Cosmic Theme Pomodoro Timer Flashcards Practice Questions Exam Countdown

Visual Theme: Night Sky / Cosmic — deep near-black navy background, violet and cyan radial glows, slow-drifting glowing particle animation, and a fixed cosmic navigation bar.

  • Hero ring timer — 220px SVG circle with a violet-to-cyan gradient stroke and glow. The stroke-dashoffset animates as time depletes. 4 Pomodoro cycles with progress pips below.
  • Mission Clock strip — Set exam date + subject → shows days remaining as a compact horizontal card beneath the timer.
  • Flashcard system — Add manually or generate from uploaded files via Groq AI (5–15 cards). Study mode flips cards with a 3D CSS perspective transform. "Guess It" mode shuffles cards, tracks correct/wrong, and shows a progress bar.
  • Practice Questions — Upload any file → Groq AI generates up to 50 questions across: Multiple Choice (4 options), True/False, Short Answer, Fill in the Blank. Each question has an explanation from Groq AI on reveal.

Schedule /schedule/

Weekly Planner Notifications

Standalone weekly planner page. A 7-column grid shows the current week with today highlighted. Add session blocks to any day (subject, time, duration, colour). Data persists in localStorage. Browser notifications fire 10 minutes before any planned session if permission is granted.

Forest /forest/

A gallery of all trees grown across study sessions — a visual history of progress over time.

Stats /stats/

Session statistics: sessions completed, flashcard accuracy, and a study activity heatmap.

Custom Mode /custom/

Fully flexible — the student defines their own time blocks, goals, and session structure. Adapts to any hours or deadline.

04 AI Integration

All AI calls go through Django views so the API key stays on the server. The frontend never touches the key directly.

EndpointWhat It Does
/api/generate-flashcards/Reads uploaded study content, returns JSON array of {front, back} flashcard pairs (5–15 cards)
/api/generate-questions/Generates MCQ, True/False, Short Answer, and Fill-in-Blank questions from study material
/api/study-coach/Conversational AI with the student's notes as context — quiz mode, focus tips, concept explanations
/api/pdf-summary/Returns structured JSON: summary paragraph, key concepts, definitions, keywords. Cached in localStorage after first call.
/api/pdf-chat/Answers questions scoped exclusively to the current PDF's text — no hallucination beyond the document
🛡️
Error Handling

Groq quota errors (HTTP 429) are distinguished: per-minute rate limits show "wait a few seconds and try again", while daily quota exhaustion shows "try again tomorrow or upgrade your Groq API plan." All non-AI features continue to work normally when the API is unavailable.

05 Data Storage Architecture

No database is used for user study content. Only Django's auth system uses a database (for login). All study data is client-side:

StoreWhat It Holds
localStorageSession plans, timer state, user profile (grade/subjects), study streak, weekly planner blocks, PDF AI summary cache, onboarding status
IndexedDBBinary PDF and DOCX files (can store megabytes per file), text highlights, annotation notes, bookmarks per PDF page
🔒
Privacy First

Student notes, PDFs, and plans never leave the browser. Only the text content sent to Groq AI endpoints travels over the network — and only when the student actively requests an AI action. The server never stores it.

Visual Identity

Two distinct visual worlds exist in the app — chosen deliberately to match emotional context:

ExamNight Sky / CosmicDark navy, violet, cyanFocus, intensity, "mission control" urgency

The Tree Metaphor

Growth is the emotional core of studying. A tree growing visually over time gives students a reward that feels earned rather than gamified. The species tied to subjects (pine for maths via Fibonacci, olive for history as an ancient survivor) adds depth — each species has a real nature fact that appears in the widget, turning the reward into a moment of curiosity.

Typography

Playfair Display (serif) is used for headings, timers, and key numbers — it gives weight and editorial quality to important information. DM Sans handles all body text and UI labels — clean, modern, and highly readable at small sizes.

07 Anticipated Audience Questions
Why three separate modes instead of one flexible interface?
Different study contexts need different environments. A student revising the night before an exam is in a completely different mindset to someone doing 30 minutes of daily reading. The modes reflect that emotionally — Exam Mode creates urgency with the cosmic countdown and dark palette; Daily Mode creates calm with the living forest. Forcing a student to configure a single flexible interface every session adds friction that kills habits.
How is the AI used responsibly — what does Groq actually see?
Groq only receives text content the student explicitly uploads or types. Nothing is stored on the server after the response is returned. The PDF chat endpoint is scoped to only the current document's extracted text — it cannot go beyond it. Flashcard and question generation are one-way read operations. No conversation history is saved server-side.
Why localStorage instead of saving data to a real database?
For a student-focused tool, privacy matters. Notes, plans, and PDFs never leave the browser, which is meaningful when you're storing personal study material, exam schedules, and progress. The tradeoff is no cross-device sync — which could be added as an opt-in feature later with Django models and user accounts, but was deliberately not included by default.
What happens if the Groq API quota runs out mid-session?
The app detects quota errors and shows a human-readable message distinguishing rate limits ("wait a few seconds") from daily exhaustion ("try again tomorrow"). All non-AI features — the timer, flashcard flipping, schedule, tree widget, PDF viewer, and study plan — continue working normally without any AI access.
Is the app mobile-responsive?
Yes. CSS breakpoints adjust layouts at 760px and 500px. Mode cards stack vertically, the weekly planner shifts to 3 columns, navigation elements resize, and fixed-position widgets (timer widget, music bar) adapt. The timer ring is SVG-based so it scales naturally.
Why no React, Next.js, or a modern JS framework?
StudySync has page-based navigation with full loads between modes, not a single-page app. Vanilla JS handles the interactivity well, removes a build step entirely, and keeps the codebase readable without framework knowledge. Django's templating handles server-side rendering. The result is fast first load times and no dependency on npm or Node.js to run the project.
What makes this different from apps like Notion, Forest, or Anki?
StudySync combines them into one context-aware environment. Notion gives you notes but no timer or AI. Forest grows trees but has no content. Anki has flashcards but no study environment. StudySync's key differentiator is the session plan as the connecting thread — one form at the start sets the subject, topic, goal, and hours, and every feature (timer, AI coach, flashcards, practice questions, tree species) responds to that plan contextually.
What would you build next if you had more time?
Spaced repetition algorithm for flashcards (currently random shuffle), cross-device sync by saving plans to the Django database as an opt-in, collaborative study rooms where two students share a timer and whiteboard, export of stats and session history as PDF, and a proper mobile app wrapper using a PWA manifest and service worker for offline AI caching.
How does the Study Tree species system work technically?
The tree widget reads the current subject string, lowercases it, and looks it up in a JS object mapping subjects to species. Each species has a type (conifer, gnarled, deciduous), bark colours, leaf colours, and a nature fact. The Canvas 2D drawing function then uses that data to render the correct tree shape and colour. The drawing is procedural — no images, just geometry and gradients — so it scales to any canvas size.
