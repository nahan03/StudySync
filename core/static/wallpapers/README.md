# Real-footage wallpapers

Drop looping videos here and they appear automatically in **Appearance -> Real footage** on the Study page.

- Formats: `.mp4` (H.264) or `.webm`. Keep clips short (10-30 s, seamless loops work best) and under ~25 MB;
  1080p is plenty. Audio is ignored (the wallpaper is always muted).
- Optional preview picture: a `.jpg` with the same name (`rain-window.mp4` + `rain-window.jpg`).
- The display name comes from the file name: `rain-window.mp4` -> "Rain Window".
- Only use footage you are allowed to use. Free libraries such as Pexels and Pixabay allow free use
  (check each clip's licence), and videos you filmed yourself are always fine.

Users can also pick a video from their own device with **My video**; that file stays on their device.
